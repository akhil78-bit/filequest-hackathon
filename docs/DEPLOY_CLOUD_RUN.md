# Cloud Run deployment playbook (required by event)

Official sources:
- https://docs.cloud.google.com/run/docs/deploying-source-code
- https://docs.cloud.google.com/run/docs/container-contract
- https://github.com/GoogleCloudPlatform/cloud-run-samples

## Prerequisites
- Google Cloud account/project with billing configured as required, permission to create Cloud Run / Cloud Build / Artifact Registry resources, and `gcloud` CLI installed.
- The user's explicit approval to deploy, enable services and incur possible charges.
- Root package.json + package-lock.json generated by Vite scaffold; `npm run build` succeeds and generates `dist`.
- Dockerfile and `server.mjs` provided in kit; `.dockerignore` excludes .git, node_modules, etc.

## Local preflight
```bash
npm ci
npm run build
PORT=8080 node server.mjs
```
Open http://localhost:8080/ and http://localhost:8080/healthz . On Windows PowerShell use `$env:PORT=8080; node server.mjs`.

## Authenticate and deploy (replace placeholders)
```bash
gcloud auth login
gcloud config set project YOUR_PROJECT_ID
gcloud services enable run.googleapis.com cloudbuild.googleapis.com artifactregistry.googleapis.com
gcloud run deploy filequest --source . --region asia-south1 --allow-unauthenticated --project YOUR_PROJECT_ID
```
These commands can create billable cloud resources. `asia-south1` is a convenient proposed region in India, **not** an event requirement. Use a region available to your project. Deploy from source uses Dockerfile if present, building a container via Cloud Build.

## Smoke test before submission
- Copy the *actual* HTTPS URL from successful gcloud output; do not guess.
- Open it in an incognito browser with no account permissions and verify the app appears.
- Check `https://YOUR_CLOUD_RUN_URL/healthz` returns `ok` (no login).
- Use a synthetic ZIP and download an organized ZIP; verify content. Check no console/network errors.
- Update README with deployed link and local run commands; run repository checker and push main.

## Cost/credentials guidance
- No Gmail, Gemini, database or secret keys needed for MVP. The production service serves static app files only; ZIP processing happens in the browser.
- Google Cloud billing, build, storage and request charges or quota restrictions may apply. Budget alerts are useful but are not guaranteed hard spending caps.
- Do not commit `gcloud` credentials, service account JSON, `.env`, or local ZIPs.
